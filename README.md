# Gold and DXY Intraday Review: Claude handover

Material for running educational intraday Gold (OANDA:XAUUSD) and DXY (TVC:DXY) chart reviews in a Claude Project. Snapshot dated 13 November 2026 (EAT, UTC+3).

| File | Use |
|---|---|
| `Gold_and_DXY_Handover_for_Claude.md` | Original handover, unchanged |
| `project-instructions.txt` | Paste into **Set project instructions** |
| `Gold-Playbook-v1.1.txt` | Upload to **Project knowledge** |
| `prompts/01-first-message.txt` | First message in a new project chat |
| `prompts/02-session-review.txt` | Template for each fresh review (fill the brackets) |
| `history/2026-11-13-historical-handoff.txt` | Optional historical review and user-reported trade log. Not live levels or position status |

## Setup

1. At https://claude.ai/projects choose **+ New Project** and name it **Gold and DXY Intraday Review**.
2. Paste `project-instructions.txt` into the project instructions.
3. Upload `Gold-Playbook-v1.1.txt` to project knowledge.
4. Start a chat with `prompts/01-first-message.txt`, then use `prompts/02-session-review.txt` with fresh, timestamped charts and news.
